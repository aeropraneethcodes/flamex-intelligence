# FlameX — 90-second judge walkthrough

**Opening (10 seconds):** “Our challenge is not to create a fire-safety verdict from incomplete data. It is to find the right NASA evidence, calculate what that evidence supports, and reveal the missing measurements.”

**Investigations (20 seconds):** Show Investigation explorer. Compare FLEX (liquid droplet), BASS-II (solid samples), and Saffire (larger-scale spacecraft tests). Explain that the system ranks *source relevance*, not material flammability risk.

**Measurements (25 seconds):** Open Fuel comparison lab. Show the FLEX fuel slopes and Brown–Forsythe residual comparison. Explain that 258 complete pairs support the model, but the observed variance difference is not direct physical flame stability.

**FlameIQ (20 seconds):** Ask: “Can these data prove that a lunar habitat is safe?” Show the unsupported-claim refusal. Open the source links / scientific calculation so the judge can check the evidence.

**Source audit (15 seconds):** Open NASA data lab. Show the NASA PSI manifest, explain the existing 274 source rows, checksum, and original table upload/audit path for BASS-II, Saffire, and SAME-R.

**Close:** “Our strongest result is knowing exactly which claims the data can support, and which claims NASA still needs more evidence to answer.”
